\# Supplementary Pre-Index Benchmark



These results were collected before equivalent inline-property indexes were

created. They are retained only to document the effect of index configuration.



They are not the primary query-performance results reported in the manuscript.



The definitive comparison is the indexed, randomized, paired benchmark stored in:



\- `../paired\_query\_performance\_raw\_runs.csv`

\- `../paired\_query\_performance\_statistical\_summary.csv`



Because the pre-index configurations did not provide equivalent indexed access

paths, these results must not be interpreted as evidence that 5GNF generally

outperforms indexed inline properties.
